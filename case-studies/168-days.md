# 168 DAYS Mini App

**Category:** Product Prototype / Telegram Mini App / Frontend  
**Repository:** https://github.com/romanlozynskyi/168-days-mini-app  
**Source code:** Public

## Overview

168 DAYS is a mobile-first frontend prototype for a Telegram Mini App built around an interactive startup reality show.

The prototype presents a premium gamified experience where viewers can follow startup cards, vote on decisions, earn XP, and manage a profile.

## Stack

`Next.js App Router` `TypeScript` `Tailwind CSS` `React local state`

## Product scope

- Mobile-first application shell
- Startup cards and content flows
- Voting interactions
- XP and gamification concepts
- Profile experience
- Responsive layout optimized around a Telegram-style mobile viewport

## Prototype boundary

This repository is intentionally frontend-only. It uses mock data and does not contain a production backend, payment integration, or Telegram Bot API implementation.

That boundary makes the repository useful as a clear public example of product interface development without exposing private production systems.

## What this case demonstrates

- Product prototyping
- Mobile-first UI development
- Next.js application structure
- TypeScript
- Tailwind CSS
- Gamified interface design
- Clear separation between prototype and production scope
